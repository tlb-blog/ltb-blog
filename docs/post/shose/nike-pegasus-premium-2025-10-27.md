ナイキのランニングシューズの代名詞とも言える「ペガサス」シリーズ。1983年の登場以来、「あらゆるランナーのためのシューズ」として、その万能性と信頼性で多くのランナーに愛されてきました。そのペガサスシリーズに、**シリーズ史上最高のエネルギーリターン**を謳い、革新的なテクノロジーを搭載した最上位モデル、**「ナイキ ペガサス プレミアム」**が加わりました。

本記事では、この「プレミアム」の名にふさわしい一足が、従来のペガサスと何が異なり、どのようなランナーに適しているのかを徹底的にレビューします。

## 1. プレミアムたる所以：3つのテクノロジーの融合

「ナイキ ペガサス プレミアム」の最大の特徴は、ナイキが誇る最も強力な3つのクッショニングテクノロジーを組み合わせた、**多層構造のミッドソール**にあります [1]。このトリプルスタック構造こそが、このシューズの「プレミアム」な走り心地を生み出しています。

### **革新的なミッドソール構造**

| 部位                  | 素材/技術                                | 特徴と役割                                                                                                                                                                                     |
| :-------------------- | :--------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **最上層** (足の真下) | **ZoomXフォーム**                        | ナイキのレーシングシューズにも採用される、軽量で極めて高い反発性を持つフォーム。足裏からダイレクトにエネルギーリターンを促進します。                                                           |
| **中央層**            | **立体的なフルレングスAir Zoomユニット** | Air Zoomユニット史上初めて、**ランナーの足の自然な形状に合わせて立体的に成形**されたユニット [2]。かかとからつま先までフルレングスで搭載され、効率的な体重移動と強力な反発力を提供します [3]。 |
| **最下層** (かかと)   | **ReactXフォーム**                       | 優れた安定性と耐久性を持ちながら、高い反発性も兼ね備えるフォーム。Air Zoomユニットの土台として機能し、着地時の安定感を高めます [1]。                                                           |

この構造は、従来のペガサス（例：ペガサス 41）が前足部と踵部に内蔵型のAir ZoomユニットとReactXフォームを採用しているのに対し、**フルレングスの立体Air ZoomユニットをZoomXフォームとReactXフォームで挟み込む**という、まさに「プレミアム」な設計です。特に、**AIなどの最新テクノロジーを駆使して開発された**立体的なAir Zoomユニットは、ペガサスシリーズにおける画期的なイノベーションと言えます [2]。

## 2. 走行感：速度によって表情を変える「じゃじゃ馬」

従来のペガサスが「クッション性、安定性、反発性をバランスよく備えた優等生」であるのに対し、「ペガサス プレミアム」は、その走行感において**明確な個性**を持っています [3]。

### **スローペースでの快適性**

走り出しやスローペースでのジョグでは、まず**ZoomXフォームとReactXフォームによる高いクッション性**を感じることができます。ソフトなフォームが着地時の衝撃をしっかりと吸収し、快適なライド感を提供します。このため、ジョグやLSD（ロング・スロー・ディスタンス）といった比較的ゆっくりとしたペースでも、足への負担が少なく、快適に走り続けることが可能です [3]。

### **ペースアップ時の爆発的な反発力**

しかし、このシューズの真価は**ペースを上げた時**に発揮されます。スピードを上げていくと、中央に配置された**フルレングスの立体Air Zoomユニット**が際立ち、**弾むような大きなエネルギーリターン**を感じることができます [3]。

この反発力は、ランナーに「走っていてとても楽しい」と感じさせるほどの推進力を生み出します。レビューでは、「シリーズ史上最高のエネルギーリターンを誇る」というナイキの謳い文句が裏付けられており、ランナーの走力やペースによって、クッションシューズとしても、反発性の高いテンポアップシューズとしても機能する**二面性**を持っています [3]。

## 3. どのようなランナーにおすすめか

「ナイキ ペガサス プレミアム」は、その革新的なテクノロジーとユニークな走行特性から、以下のようなランナーに特におすすめできます。

| ターゲットランナー                                     | おすすめの理由                                                                                                                 |
| :----------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------- |
| **ナイキの最先端技術を体感したいランナー**             | ZoomX、立体Air Zoom、ReactXという3つの最新技術を一度に体験できる、まさに技術の結晶です。                                       |
| **ランニングに「楽しさ」を求めるランナー**             | 弾むようなライド感は、日々のランニングに新鮮な刺激と楽しさをもたらします [3]。                                                 |
| **日々のトレーニングでペースの緩急をつけたいランナー** | スローペースではクッション性を、ペースアップ時には反発性を得られるため、ジョグからテンポ走まで幅広いトレーニングに対応します。 |
| **従来のペガサスに物足りなさを感じていたランナー**     | 万能だが刺激が少ないと感じていたランナーにとって、プレミアムの爆発的な反発力は新たな選択肢となります。                         |

## 4. まとめ

「ナイキ ペガサス プレミアム」は、単なるペガサスのアップグレード版ではなく、**ペガサスシリーズの歴史に新たな一歩を刻む革新的なモデル**です。

**万能な「ペガサス 41」**が日々の安定した走りをサポートする「優等生」であるなら、**「ペガサス プレミアム」**は、最先端のクッショニング技術を駆使し、**ランニングの楽しさと爆発的な反発力**を提供する「じゃじゃ馬」と言えるでしょう [3]。

ナイキ史上最高のエネルギーリターンを誇るこの一足を体験し、あなたのランニングを次のレベルへと引き上げてみてはいかがでしょうか。
